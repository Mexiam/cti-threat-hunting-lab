# CTI Threat Hunting Lab

> CTI-driven threat hunting laboratory focused on translating real-world
> cyber campaigns into detection and threat hunting use cases.

## Objective

This project aims to evaluate the ability of a controlled laboratory
environment to detect behaviors observed during real-world cyber campaigns.

The project combines:

- Cyber Threat Intelligence
- MITRE ATT&CK
- Detection Engineering
- Sigma
- Wazuh
- Threat Hunting
- Python automation
